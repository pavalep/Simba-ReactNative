V17 Phase 84: downloadsStore (persist, the last redux slice)

`downloadsSlice` -> `useDownloadsStore` (Zustand + persist, key
'downloads' to match the redux-persist whitelist). This is the
**last** redux slice. The Phase 85 sweep is now mechanical.

Reactive UI mirror of `downloadService` (the service's
AsyncStorage manifest remains the source of truth; this store
feeds badges, buttons, the Downloads screen). The 4 actions
(`hydrateDownloads`, `upsertDownload`, `setDownloadStatus`,
`removeDownload`) are preserved 1:1.

The 3 derived selectors (record-by-URI, downloaded-URI set,
total bytes) become hooks with the same name pattern as the
media store:
  - `useDownloadByUri(uri)` -> DownloadRecord | null
  - `useDownloadedUriSet()` -> Set<string>
  - `useDownloadsTotalBytes()` -> number

Each memoizes on the `records` reference, so re-renders are
contained to the records themselves, not to the source of
truth in the service.
