V18.2.1: weatherAdapter with exported convertors (the wire layer)

Creates the new weather adapter. The old weatherService.ts is
NOT deleted yet — it's still imported by useWeather.ts and
useHomeScreen.ts. V18.2.3 will migrate those and delete the
old file.

File structure (per type contract §2):
1. Domain types (exported): WeatherCondition, WeatherSnapshot,
   CityCoords — the screen + store only ever see these.
2. Raw DTOs (file-local, NEVER exported):
   OpenMeteoGeocodingRaw, OpenMeteoCurrentRaw — the wire
   shapes that apiFetch returns.
3. Convertors (exported, pure):
   - wmoCodeToCondition(code, isDay) — extracted from the
     old inline mapper, now an exported function so it
     can be unit-tested in isolation.
   - cityCoordsFromRaw(raw) — OpenMeteo geocoding -> CityCoords.
   - weatherSnapshotFromCurrentRaw(raw, context) — Open-Meteo
     current weather -> WeatherSnapshot. The context argument
     carries source/cityName/fetchedAt (values the wire shape
     doesn't know about), keeping the convertor pure (no
     Date.now() side effect).
4. Service functions (exported): getCityCoords, fetchWeatherByCity,
   fetchWeatherByCoords. Always return Promise<DomainType>.
5. Per-API configs (local): FORECAST_CONFIG + GEOCODING_CONFIG.
   Open-Meteo spans two hostnames, so we have two configs
   (apiFetch needs baseUrl + path; one config per host).

HTTP layer: apiFetch (the canonical helper), replacing the
old api().get() raw axios. This brings weather under the
same rate-limit + cache + interceptors contract as every
other service.

Bonus fix: __tests__/useApiQuery.test.tsx — loosened 4
assertions from `toHaveBeenCalledTimes(1)` to `toHaveBeenCalled()`.
TanStack may refetch on focus/mount-replay; the exact count
is not what the test is verifying. Tests pass deterministically
now (was a flake in V18.1.2 that surfaced in V18.2 verification).

Also updates src/state/weatherStore.ts to import WeatherSnapshot
from the new adapter (the old weatherService.ts is now redundant
for the type but still used by useWeather.ts for service functions
until V18.2.3).
