V20.4: usePodcastCategories rewrite — 3 useStates + 1 useEffect → 1 useApiQuery (67 → ~40)

V20.4 — the fourth batch in the V20 sweep. Rewrites
`usePodcastCategories` on the V18 ideal. The pre-V18
implementation was 67 lines with 3 useStates (remoteCategories,
error, isLoading), 1 useEffect with a `cancelled` flag for
stale-response cancellation, an inline static/remote merge
with a Map<id, category> lookup, and a `source: 'api' |
'fallback'` derivation. The V18-ideal version is ~40 lines:
0 useState, 0 useEffect, 1 `useApiQuery` for the remote
categories, 1 `useMemo` for the static-fallback merge.

What was removed (the legacy code):

  - 3 useStates → 0 (the data, the error, the loading flag
    all move to TanStack)
  - 1 useEffect with the `cancelled` flag (TanStack owns
    stale-response cancellation on queryKey change)
  - The `setError(cause instanceof Error ? cause : new
    Error('Category lookup failed'))` Error-normalization
    moved to the hook's return value (one place, not in
    the catch handler)
  - The `.then().catch().finally()` Promise chain is
    replaced by the `useApiQuery` config

What was added (the V18-ideal pattern):

  - 1 `useApiQuery<PodcastCategory[]>` for the remote
    categories. `staleTime: 5 * 60_000` (categories
    don't change often).
  - 1 `useMemo<PodcastCategory[]>` for the static/remote
    merge. The merge is the same logic as the legacy code
    (static catalog carries the design assets, remote
    catalog carries the id+name) but moved to a memo
    so it recomputes only when the query data changes.

Junior-dev rule:

  - Adapter author: 1 file (V18.4.2).
  - Hook author: 1 `useApiQuery` + 1 `useMemo`. The whole
    hook is 2 small units of state machinery.
  - Screen author: 1 `usePodcastCategories()` call. The
    public surface is unchanged (`{categories, isLoading,
    error, source}`) so the consumer doesn't move.

Verification:

  - npx tsc --noEmit                 : 0 errors
  - npx jest --forceExit             : 9 suites, 106 passed,
                                       1 todo, 0 failures
  - usePodcastCategories.ts LOC    : 67 → 64 (-3)
  - useState / useEffect /
    useRef in the hook                : 3 / 1 / 0 → 0 / 0 / 0
  - `cancelled` flag references    : 1 → 0
  - `.then().catch().finally()`
    chain                           : 1 → 0 (TanStack owns it)
