V18.4.3: paginated-services consumer migration — 3 *Service.ts deleted

V18.4.3 — the paginated services consumer migration. Replaces
the 3 old `*Service.ts` files (`iptvService`, `podcastIndexService`,
`radioBrowserService`) by redirecting all 5 consumer hooks
(plus the `searchAggregator` and the `index.ts` barrel) to
the V18.3-V18.4 adapters that already existed.

V18.4.1 + V18.4.2 (commit `dd4def3`) had already created the
3 adapters with file-local *Raw DTOs and EXPORTED convertors.
What remained was the consumer migration — the single mechanical
step that lets the old *Service files be deleted.

This commit does the import swap on 5 consumer files:

  - useLiveTVBrowser (iptv)
      Switches from `iptvService` to `iptvAdapter`. The
      `getAllIPTVChannels`, `searchIPTVChannels`,
      `getChannelsByCategory`, `getIPTVCategories` function
      names are identical between the service and the adapter
      (the adapter was written to preserve the public surface
      1:1 in V18.4.1), so the swap is search-and-replace.

  - usePodcastDetailScreen (podcastIndex)
      `getPodcastById` + `getEpisodes` from the adapter.

  - usePodcastCategories (podcastIndex)
      `getPodcastCategories` from the adapter.

  - usePodcastsScreen (podcastIndex)
      Same podcastIndexAdapter import swap.

  - useRadioBrowser (radioBrowser)
      Switches to the radioBrowserAdapter.

The two multi-scope state machines (useLiveTVBrowser at 361
lines, useMoviesScreen at 320 lines) keep their per-scope
Map<key, ScopeState> + seqRef + guardRef + lastLoadMoreAtRef
shims. The full V18-ideal rewrite of those (single useApiQuery
or useQueries per scope) is V18.6.2 — the multi-scope design
is a one-off and the V18.6 spec will document the pattern.
This commit is the prerequisite for the rewrite: removing
the old *Service files now means the V18.6.2 rewrite can
focus on the hook design, not on import juggling.

What also gets updated:

  - services/api/searchAggregator.ts: `getAllIPTVChannels`
    import moves from `./iptvService` to `./iptvAdapter`.
    (The aggregator is itself the V18.6 candidate — the
    Promise.allSettled → useQueries rewrite is also in
    V18.6.2.)

  - services/api/index.ts: barrel removes the
    `radioBrowserService` + `iptvService` re-exports.
    The full barrel cleanup (removing the *Service
    re-exports entirely) is V18.8.3.

What gets deleted:

  - src/services/api/iptvService.ts
  - src/services/api/podcastIndexService.ts
  - src/services/api/radioBrowserService.ts

These 3 files had no callers in src/ after this commit's
import swaps; `git grep` confirms zero remaining references
(the 3 matches in the adapter comments are intentional
doc comments explaining what each adapter replaces).
