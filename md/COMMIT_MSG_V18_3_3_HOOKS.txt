V18.3.3: migrate 2 representative consumer hooks to useApiQuery

Migrates two consumer hooks from the pre-V18
`useState + useEffect + useRef` state-machine pattern to the
V18 `useApiQuery` family. These are the first two of the 11
hooks that the V18.3.3 phase will eventually cover; the rest
are staged for follow-up commits (the shim files from
V18.3.3-prep mean the unmigrated hooks still work).

### 1. src/hooks/useMoreFromArtist.ts (jamendo — simple)

Was: 46 lines, useState[tracks, isLoading] + useRef[fetchingRef]
+ useEffect + useCallback[load, retry]. Manual dedupe via the
`fetchingRef` guard, manual retry via the `retry` callback.

Now: 47 lines, one `useApiQuery` + one `useMemo` for the
exclude-filter + one `refetch` wrapper. TanStack handles the
loading + dedupe + retry; the hook returns the same public
shape `{tracks, isLoading, retry}` so the consumer doesn't
change.

The `enabled: artistName.trim().length > 0` flag replaces
the original `if (!artistName.trim()) return` early exit.

### 2. src/screens/Library/hooks/useAlbumEnrichment.ts (musicbrainz — mid)

Was: 70 lines, useState[releaseGroup, isLoading] +
useRef[fetchingRef] + useEffect + useMemo[matchedCount].
The zustand-derived `localTracks` selector is pure (read-only
snapshot of the local library); the fetch is the only async
piece.

Now: 56 lines, one `useApiQuery` + the same useMemo for
matchedCount. The zustand selector stays as-is. The
`enabled: !!releaseGroupId` guard replaces the early-exit.
The `releaseGroup: releaseGroup ?? null` coerces TanStack's
`T | undefined` to the consumer's `T | null` (preserves the
original contract).

### Migration pattern (carries to the remaining 9 hooks)

```ts
// before
const [data, setData] = useState<X | null>(null);
const [isLoading, setIsLoading] = useState(false);
const fetchingRef = useRef(false);
useEffect(() => { /* fetch + setData + setIsLoading */ }, [deps]);

// after
const {data, isFetching, refetch} = useApiQuery<X | null>({
  queryKey: ['<svc>', '<method>', ...deps],
  queryFn: () => svc.method(...),
  enabled: <guard>,
  staleTime: <ttlMs>,
});
return {data, isLoading: isFetching, refetch: () => void refetch()};
```
