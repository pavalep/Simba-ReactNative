V18.6.2d: searchAggregator dead-code deletion + QueriesOptions rename + stale comment fix

V18.6.2d — the closeout of the V18.6 series. Three small
fixes that came up after V18.6.2a (useAggregatedSearch →
useApiQueries).

What was deleted (V18.6.2d.1):

  - `src/services/api/searchAggregator.ts` — 50 lines. The
    aggregator's `aggregateSearch(query, options)` function
    was the pre-V18.6 "5 parallel `Promise.allSettled`" entry
    point. After V18.6.2a, `useAggregatedSearch` builds the
    5 parallel queries directly via `useApiQueries`; the
    aggregator had no consumer. The only remaining reference
    to it was a stale comment in `SearchScreen.tsx` (the
    actual call site is `useAggregatedSearch(debouncedQuery)`,
    not the aggregator directly). SearchScreen comment is
    updated in this commit.

What was fixed (V18.6.2d.2):

  - `src/hooks/useApiQuery.ts` — V18.6.2a introduced the
    `useApiQueries` wrapper. I imported the type as
    `UseQueriesOptions` (which doesn't exist in TanStack v5).
    The correct name is `QueriesOptions`. This was masked
    by the fact that the test (`useApiQuery.test.tsx`) had
    explicit type annotations on its `combine` callback,
    so the test passed; the tsc error only surfaces when
    the searchAggregator deletion removes the last
    "consumer of `useApiQueries` through `useAggregatedSearch`"
    path. Fixed in this commit.

  - `src/screens/Search/components/SearchScreen.tsx:105` —
    the comment `// P40.1: remote sources via
    searchAggregator (debounced + cancelled)` is updated to
    the V18.6 reality: "V18.6.2a: remote sources via 5
    parallel useApiQuery calls inside useAggregatedSearch
    (debounced + per-source error isolation)."

Why V18.6.2d is the closeout of V18.6:

  - V18.6.2a added `useApiQueries` + rewrote `useAggregatedSearch`
  - V18.6.2b rewrote `useLiveTVBrowser` (per-scope Map retired)
  - V18.6.2c rewrote `useMoviesScreen` + provider + content
  - V18.6.2d deletes the searchAggregator dead code + fixes
    the type import + the stale comment
  - V18.7.3 (useDownloadsSync audit) is the only remaining
    V18.6-era item; it's likely a "no change needed" commit
