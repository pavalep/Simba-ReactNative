V18.3.3 (batch 2): migrate 4 more simple consumer hooks

Migrates 4 more single-fetch / dual-fetch consumer hooks to
useApiQuery. Pattern follows the V18.2.3 / batch-1 design:
1 useApiQuery per hook, queryFn encapsulates the full fetch
flow, TanStack handles loading / retry / cache.

### 1. useAudiobookDetailScreen (librivox + internet archive)

Was: 58 LOC, useState[book, chapters, isLoading, error] +
useEffect + useCallback. Sequential fetch (book first, then
chapters).

Now: 47 LOC, single useApiQuery. The book + chapters fetch
stays sequential inside the queryFn (the second call needs
the first result). `getAudiobookById` now imports from
`librivoxAdapter`; the Internet Archive service stays
imported from its legacy file (Wave 5 will migrate it).

### 2. useMusicDetailScreen (jamendo | audius — discriminated)

Was: 58 LOC, useState[track, isLoading, error] + manual
`cancelled` flag. Two fetch paths based on `source`.

Now: 35 LOC, single useApiQuery. The `source` is part of
the queryKey so the cache separates the two. The conditional
fetch (jamendo with parsed-int ID vs audius with string ID)
lives inside the queryFn.

### 3. useShowDetailScreen (tvmaze — dual parallel fetch)

Was: 105 LOC, useState[show, episodes, isLoading, error] +
useRef[fetchingRef] + useEffect + 2 useMemo derivations.

Now: 85 LOC, single useApiQuery. The parallel
`Promise.all([getShowById, getEpisodeList])` stays inside
the queryFn. The `seasons` and `matchedCount` useMemo
derivations stay as-is (pure transforms over the query data
+ the zustand `localVideos` selector).

### 4. useArtistEnrichment (musicbrainz — 2-step with graceful
fallback)

Was: 60 LOC, useState[artist, releases, isLoading] +
useRef[fetchingRef] + useEffect with `cancelled` flag. The
graceful local-only fallback (P39.6) was an empty catch
block.

Now: 51 LOC, single useApiQuery. The graceful fallback is
preserved by catching inside the queryFn and returning the
empty state — TanStack never sees the throw, so the
consumer's `isError` stays false. The `enabled: artistName
trim().length > 0` guard replaces the early-exit.
