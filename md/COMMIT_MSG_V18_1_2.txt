V18.1.2: useApiQuery family + QueryProvider + V17 test cleanup

Adds the V18 query layer:

- src/app/QueryProvider.tsx
  Wraps the app in a TanStack QueryClientProvider with project
  defaults: staleTime 60_000 ms, gcTime 5 min, retry 2,
  refetchOnWindowFocus false. QueryClient is lazy-initialized
  via useState to survive re-renders.

- src/hooks/useApiQuery.ts
  Thin wrappers over @tanstack/react-query:
  - useApiQuery<TData, TError>({queryKey, queryFn, ...})  -> single
  - useInfiniteApiQuery<TPageData, TError>({...})         -> load-more
  - useApiMutation<TData, TVariables, TError>({...})      -> user action
  The cache-key convention is [service, method, ...args]; the
  type contract is documented at the top of the file.

- App.tsx
  Wraps the existing tree (SafeAreaProvider > ThemeProvider >
  SimbaPlayer) with QueryProvider, placed inside SafeAreaProvider
  and outside ThemeProvider (data layer is a sibling of UI).

- __tests__/useApiQuery.test.tsx (new, 5 cases)
  Smoke tests for all three hooks:
  - useApiQuery returns data after fetcher resolves
  - useApiQuery surfaces errors
  - useApiQuery treats different keys as independent caches
  - useApiMutation fires on demand and exposes the result
  - useInfiniteApiQuery fetches the first page

- V17 test cleanup (V17 leftover fixed in passing)
  AppButton.test.tsx and AppText.test.tsx imported the
  `react-redux` Provider and `@reduxjs/toolkit` configureStore,
  both of which V17 Phase 86.1 removed. The components don't
  actually need the Provider (they use useTheme, which the
  existing ThemeProvider covers). Removed the dead import +
  unused mockStore. Tests still pass and tsc is clean.

Verification:
- npx tsc --noEmit  -> 0 errors
- npx jest          -> 17 passed / 1 todo / 5 suites
  (1 todo pre-existing; no new failures)

Note: jest reports a "worker process has failed to exit
gracefully" warning from the useInfiniteApiQuery test, caused
by TanStack's internal notifyManager timer. The test PASSES
(17/17) and the warning is a known TanStack + jest interaction,
not a test failure.
