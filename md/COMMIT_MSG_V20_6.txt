V20.6 — 5 V18 minor-cruft cleanups (useWeather onSuccess was a misdiagnosis)

Five of the six audit findings from V20.6 are fixed; the sixth
(useWeather onSuccess) was a misdiagnosis because TanStack v5
removed `onSuccess` / `onError` from `useQuery` (they only exist
on `useMutation` now). The useEffect mirror in useWeather is
already the canonical v5 shape — the comment in the file now
documents this.

The 5 fixes that landed:

  1. `useMoviesScreen:159-161` — `useMemo` used as a side
     effect (`setDisplayCount(PAGE_SIZE)` inside a memo) is
     converted to `useEffect`. The dependency array stays the
     same; only the hook kind changes. The `useEffect` import
     was added.

  2. `useAggregatedSearch:164-174` — the 3-tier `isLoading`
     ternary that compared per-source arrays by reference
     against a module-level `EMPTY` is replaced by a per-source
     `isFetching ||` OR computed inside the `combine` callback.
     The `EMPTY` module-level constant is deleted. The combine
     now returns `{results: AggregatedSearchResults; isLoading:
     boolean}` and the hook's `isLoading` becomes `enabled &&
     combined.isLoading` — the "is any source still loading,
     and we asked them to load?" question in one line. The
     consumer (`SearchScreen`) didn't move — the public
     `AggregatedSearch` shape is unchanged.

  3. `useSettingsScreen:72` — the dead `const [isLoading,
     _setIsLoading] = useState(false)` is removed. The
     returned `isLoading` is now derived from `isScanning`
     (the only thing that actually loads in this screen —
     the media-library scan). The consumer's loading-overlay
     still works because the media scan is what triggers it.
     The public `isLoading` field is preserved.

  4. `useSongScreen:138-152` — the manual LRC fetch (1
     `useState<LrcLine[]>`, 1 `useState<boolean>`, 1
     `useEffect` with a `mounted` flag) is replaced by a single
     `useApiQuery` with `staleTime: Infinity` (the LRC for a
     given `fileUri` never changes, so we cache it for the
     app lifetime). The `queryFn` is the existing `loadLrc`,
     wrapped in a `useMemo` to flatten `result.lines ?? []`.
     The public `lyrics` and `lyricsLoading` return fields are
     preserved (no consumer change).

  5. `useNetworkStatus` — the unused `wasEverOffline` ref
     (written on every offline event, read by zero consumers)
     is removed. The `wasEverOffline` field on the returned
     object and the `NetworkStatus` interface are gone. The
     `useRef` import is no longer needed. No consumer change.
