V18 docs+code audit: align spec/tracker/plan with Wave 11 actuals

The post-V18.11.6 closeout audit (12 discrepancies between
docs and code) is resolved in this single commit. One real
code bug + 9 doc alignments.

The bug:
  - src/screens/Genre/hooks/useGenreScreen.ts
    The V18.11.4 commit dropped the "Radio" tab from the
    UI but the hook still had a `useApiQuery<RadioStationResult[]>`
    call plus `radioStations`, `radioLoading`, `radioFailed`,
    `retryRadio`, `handlePlayStation` on the result interface.
    The screen never consumed any of these. The fix removes
    the dead useApiQuery, the unused callbacks, the unused
    `getStationsByGenre` import, and the unused `RadioStationResult`
    import. Net effect: the hook is now exactly what the spec
    says it should be — one `useApiQuery` (streaming) + a
    zustand selector (local). This is the exact kind of
    "per-scope cache dead code" Wave 11 was supposed to retire.
